# ADB 命令大全

Android Debug Bridge 常用命令速查，按场景分类整理，支持关键词检索与一键复制。

## 覆盖范围

- 设备管理（连接/列表/无线调试）
- 应用管理（安装/卸载/启动/权限）
- 文件操作（push/pull）
- 日志与调试（logcat/dumpsys/bugreport）
- 截屏录屏
- 系统属性与设置
- Shell 与进程

## 适用场景

- 日常 Android 开发调试
- 设备状态检查与问题定位
- 自动化脚本编排
