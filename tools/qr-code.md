# 二维码生成

文本或 URL 一键生成二维码，实时预览，支持下载 PNG 与复制 data URL。

## 功能

- 容错等级 L/M/Q/H 四档可调（越高越抗损）
- 尺寸 128–512px、边距 0–6 可调
- 输入变化自动重新生成（防抖）
- 下载 PNG、复制 data URL
- 深色主题适配：深底浅码

## 适用场景

- 分享链接到移动端
- 给文本/网址生成可扫描码
